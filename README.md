# samiali38183.github.io

Personal portfolio site for Sami Ali — cybersecurity student, DHS HS-POWER intern at CBP Vulnerability Assessment Team.

Static site, no build step. `index.html` + `styles.css` + `main.js`. Deploys from repo root on the default branch via GitHub Pages.

Live: https://samiali38183.github.io

## Local preview

Open `index.html` in a browser, or:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000
