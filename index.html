AppSec · static analysis

sinkline

Interprocedural taint analysis for Python web apps, mapped to the OWASP Top 10.

Problem
Pattern-matching linters flag every cursor.execute, whether the argument came from a config file or from request.args. A reviewer needs to know which sinks attacker-controlled bytes can actually reach.
What it does
Abstract interpreter over Python ast with two-pass function summaries, CWE-scoped sanitizers and validation-guard recognition. Reports the full source → call → sink path and a fix. Emits SARIF for GitHub code scanning. 138 sink signatures, 42 rules, zero dependencies. On a 109-line labeled corpus: precision 0.983 / recall 0.951 (bandit on the same corpus: F1 0.579) — the score is a CI gate.

Vulnerability management

kev-risk-prioritization

Risk-based prioritization with CISA KEV, EPSS, CVSS and asset criticality, aligned with BOD 26-04.

Problem
Scanners produce more findings than any team can fix. CVSS says how bad an exploit could be, not whether anyone is exploiting it. If you can only patch 10% of the queue this sprint, which 10%?
What it does
Written case study of the methodology from my CBP internship (public guidance only, no internal data) plus a stdlib-only reference implementation that ranks findings, compares KEV vs non-KEV populations, and matches against the live CISA KEV feed. Runs on synthetic data in the repo or your own CSV; CSV/JSON output for dashboards and ticketing.

cybersecurity-vault

Defensive labs and small tools: a phishing IOC extractor and a Wireshark traffic-analysis lab.

Problem
Pulling indicators out of raw phishing samples by hand is slow and error-prone, and encrypted traffic hides less from a defender than people assume.
What it does
Phishing IOC Extractor — stdlib .eml parser that emits deduplicated JSON of IPs, domains, URLs, emails and MD5/SHA-1/SHA-256 hashes; 10 pytest tests. Wireshark lab — TCP handshake, DNS, HTTP, TLS Client Hello (SNI), ARP and port-scan captures with display filters, what to look for, and defender relevance, including ARP-poisoning signatures (ATT&CK T1557.002).
