The stock Sigma rule for setuid abuse matched 0 of 36 events.

      
tripline is a detection quality gate. In CI it emulates ATT&CK techniques, replays the resulting telemetry through Sigma rules, scores coverage, and fails the pull request if a rule regresses. No SIEM required.

      
Running it on SigmaHQ’s “Setuid and Setgid” rule: the rule looks for the literal text chmod u+s. The Atomic Red Team test ran chmod u+xs, and the rule also misses chmod 4755. Same behavior, no alert. I wrote a replacement that matches any setuid/setgid chmod form.

  • 47%weighted ATT&CK coverage (Red Canary 2026 weights); 100% of scenarios that have logs
    • 
      

      
Not done: the 7 Windows scenarios are still pending, which is why overall coverage is 47%. Exports an ATT&CK Navigator layer.

A taint analyzer that tracks input across files, scored against bandit.

      
sinkline is an interprocedural taint analyzer for Python web apps. It follows user input from request to dangerous sink across function and file boundaries, maps findings to OWASP and CWE, and emits SARIF. Zero dependencies; built on the standard library’s ast.


      

      
Run on real intentionally-vulnerable apps: vulpy returned 3× CWE-89 across files and 0 in its good/ directory; Vulnerable-Flask-App yielded SSTI, SQL injection, XSS and weak MD5; dvpwa returned CWE-89 and CWE-117; the clean microblog app returned 0.
