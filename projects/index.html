Projects

Five tools, each with the measurements and CI runs behind its claims. Every page ends with a limitations section.

  • tripline

    Detection engineering, v0.2.1

    A CI gate that replays recorded ATT&CK telemetry through Sigma rules and fails the pull request when an expected rule stops firing. 14 scenarios, 10 passing, 4 pending (Windows); 186 tests.

  • sinkline

    Application security, v0.4.1

    A static analyzer that follows request data across functions and files and reports it only when it reaches a dangerous sink without a sanitizer for that bug class. 91 tests; 109-line self-labeled benchmark.

  • kevgate

    Vulnerability management and DevSecOps, v0.1.1

    A small API that turns scanner findings into a remediation queue ranked by CISA KEV, EPSS, CVSS and asset criticality, shipped with a container, Helm chart, Terraform and a CI security pipeline. 277 tests on main.

  • kevgate-admit

    Kubernetes security, Go

    An admission webhook that denies or warns on workloads whose image digests carry KEV-listed or over-threshold vulnerabilities. 72 tests, 95% coverage, and a kind end-to-end run in CI. It does not scan images itself.

  • fuzzdiff

    Memory safety and fuzzing, Rust

    picohttpparser ported from C to safe Rust and checked against the original with differential tests, seeded bugs and libFuzzer. 29 tests, 95.88% line coverage; Rust is about 1.4x to 1.5x slower on head parsing. No vulnerability found.
